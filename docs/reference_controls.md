# 对照结构的解释

常规新版任务应使用 `au-metal`，或默认的 `parallel` 入口：SiO2 → Au → 四聚体，直接接触金膜。

保留的 `bare-*` 预设是固定位置、固定网格的去金属对照：只把金层替换成背景介质，其他物体位置保持不动。因此，默认几何中四聚体与基板之间仍保留 100 nm 的空气间隔。它不代表四聚体直接落在裸 SiO2 上。若要比较后者，应另外构造接触裸基板的任务，不能把两种去金属定义混用。

常规新任务的 `job.json` 必须显式写入 `metal_position=above_substrate` 和 `substrate_termination=pml`。原有底部金膜任务只能在原生成器继续；新版不会自动转换已有数据或覆盖旧任务。测试工具底层保留明确指定旧层叠的能力，供本机受控对照使用，不作为新版数据生成入口。

2.1.0 按用户确认的厚基板方案：玻璃延伸穿过下方 PML，透射面在玻璃内部，没有玻璃背面的空气界面。之前的有限 350 nm 基板算例仅作为独立诊断对照。复现实验时必须显式设置 `--substrate-termination finite`；新默认是 `pml`。两类数据的配置指纹不同，不能混合。

`substrate_depth_nm` 在厚基板模式下描述计算域参考深度，不能解释为真实基板厚度。当前透射率是穿过 Au 后进入 SiO2 的归一化功率；它与有限玻璃背面再进入空气的透射率定义不同，报告会明确区分。
