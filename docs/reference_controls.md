# 对照结构的解释

常规新版任务应使用 `au-metal`，或默认的 `parallel` 入口：SiO2 → Au → 四聚体，直接接触金膜。

保留的 `bare-*` 预设是固定位置、固定网格的去金属对照：只把金层替换成背景介质，其他物体位置保持不动。因此，默认几何中四聚体与基板之间仍保留 100 nm 的空气间隔。它不代表四聚体直接落在裸 SiO2 上。若要比较后者，应另外构造接触裸基板的任务，不能把两种去金属定义混用。

常规新任务的 `job.json` 必须显式写入 `metal_position=above_substrate`。原有底部金膜任务只能在原生成器继续；新版不会自动转换已有数据或覆盖旧任务。测试工具底层保留明确指定旧层叠的能力，供本机受控对照使用，不作为新版数据生成入口。

本机示例保留有限 350 nm SiO2 基板和下方空气缓冲，以便仅改变层序作对照。若实验样品为厚玻璃基板，后续还需要另行验证基板延伸至 PML、透射监视器放置及功率归一化；不应把这项尚未完成的检查当作已通过。
